# Signal-map artwork

The playable scene renders its signal-map artwork directly in SpriteKit. The operator has a visor and equipment pack; enemy silhouettes vary by type; mission terminals are numbered and show active-task emphasis. Room panels contain machinery, status lights, floor markings, and theme-dependent colors. The blackout condition renders a moving visibility aperture around the operator.

These vector elements are part of the current scene implementation, not image files in this directory. Presentation artwork and App Store screenshot assets have separate provenance and should not be described as independently authored solely because the scene uses native vector rendering.
